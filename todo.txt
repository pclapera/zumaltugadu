NOTES
-----
- Les images et la liste des langues sont dans config.js. Les textes sont
  dans un fichier par langue (config.de.js, config.fr.js, config.en.js).

- Langue par défaut : allemand. Le choix du visiteur est mémorisé dans le
  navigateur. Ajouter une langue : voir l'en-tête de config.js.
- Palette du site : bleu glacier / neige / bois (modifiable dans les
  variables CSS en haut de zumaltugadu.html).
- Les tarifs ne sont pas affichés (demande sur devis).
- Les photos actuelles : images/ pour l'intérieur et l'entrée,
  bettmeralp_*.jpg (dossier principal) pour le village et le héro.
- Le site s'ouvre en double-cliquant sur zumaltugadu.html.
